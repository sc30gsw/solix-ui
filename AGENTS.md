# AGENTS.md

Every rule in this repository is enforced by a check. Run all of them with `vp run verify`. The same command runs before each commit and in CI.

| Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Enforced by                                                                                                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Use Vite+ for development, builds, tests, linting and formatting.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | The pnpm override that resolves `vite` to Vite+, the `vite-plus/prefer-vite-plus-imports` lint rule, and `tests/workspace-rules.test.ts`.                                                        |
| Code is formatted, lint-clean and type-correct.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `vp check --deny-warnings`.                                                                                                                                                                      |
| Code has one style for functions, imports, exports, comparisons and type assertions.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | The lint rules in `vite.config.ts`, run by `vp check --deny-warnings`.                                                                                                                           |
| No tracked file, file name or commit message names another UI library.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `scripts/check-private-terms.mjs`, in `vp run verify` and the commit-msg hook, where `SOLIX_PRIVATE_TERMS` is set. CI sets it from a repository secret.                                          |
| A component has one shape: one function per `Component.tsx`, its props typed `ElementProps` or `PolymorphicProps` with `PartProps<typeof styles>`, and one `createParts` call in `packages/core/src/parts.ts`. Its `root` is spread on the element the component returns and `part(name)` on each other part, and no `class` or `style` is written by hand. A component takes `component`, through `PolymorphicProps` and a `dynamic()` root, when its job does not depend on one element, as with `Box` and `Button`. A component whose behaviour belongs to one element, such as `details`, `dialog` or `input`, takes `ElementProps` and returns that element. The barrel is sorted, and every `--solix-*` token is used. No array or argument list outside the table in `packages/core/src/style-prop-table.ts` names two style props. | `tests/library-conventions.test.ts`.                                                                                                                                                             |
| Only `createParts` calls the StyleX runtime: in the build, `parts.js` alone calls `stylex.attrs` or `stylex.props`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `packages/core/tests/build-output.test.ts`.                                                                                                                                                      |
| A component is rendered by the app, described by a feature file, and listed in the contract skill.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `tests/library-conventions.test.ts`.                                                                                                                                                             |
| Skills, agents and this table stay true to the repository, and every agent is started by an installed skill.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `tests/repository-conventions.test.ts`.                                                                                                                                                          |

| A colour token is written in OKLCH and lies inside sRGB. In every `stylex.create` block of a component, under each condition, `color` reaches 4.5:1 contrast and each border or outline colour 3:1 against the block's `backgroundColor`, or against `--solix-color-body` when the block sets none. Each colour in such a pair is a token.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `packages/core/tests/token-contrast.test.ts`.                                                                                                                                                    |
| The library's CSS sits in one cascade layer, its classes carry the library prefix, and nothing is `!important`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `packages/core/tests/build-output.test.ts` and `packages/core/tests/stylesheet-properties.test.ts`.                                                                                              |
| Every exported component puts a consumer's class and attributes on its root, next to its own classes, and the root carries one stable root class, its own. Every key of its compiled `stylex.create` block is a rendered part and every part is a key. It puts the class and the declarations that `classes` and `styles` name for a part on exactly that part, leaves out a declaration whose value is `undefined` or `null`, and with `unstyled` keeps every stable part class and drops every library style class.                                                                                                                                                                                                                                                                                                                      | `packages/core/tests/component-contract.test.tsx`.                                                                                                                                               |
| Every exported component passes a consumer's `ref` the element that carries its root class.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `apps/playground/tests/consumer.test.ts`.                                                                                                                                                        |
| Every component takes every style prop on its root, except one its type declares `never`: `Modal` takes no `display`, `hiddenFrom` or `visibleFrom`, which would show a closed dialog. A style prop writes into `style` only the `--sx-` custom property its own class reads, and drops `null` and any value that holds `;`, `{` or `}`. Each `--sx-` custom property is registered not to inherit. A longhand style prop's rules come after its shorthand's at every breakpoint. Precedence is component default < style prop < consumer class < consumer `style`. The style-prop table that the build loads imports nothing at run time.                                                                                                                                                                                                 | `packages/core/tests/component-contract.test.tsx`, `packages/core/tests/build-output.test.ts`, `packages/core/tests/stylesheet-properties.test.ts` and `apps/playground/tests/consumer.test.ts`. |
