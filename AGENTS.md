# AGENTS.md

Every rule in this repository is enforced by a check. Run all of them with `vp run verify`. The same command runs before each commit and in CI.

| Rule | Enforced by |
| --- | --- |
| Use Vite+ for development, builds, tests, linting and formatting. | The pnpm override that resolves `vite` to Vite+, the `vite-plus/prefer-vite-plus-imports` lint rule, and `tests/workspace-rules.test.ts`. |
| Code is formatted, lint-clean and type-correct. | `vp check --deny-warnings`. |
| Code has one style for functions, imports, exports, comparisons and type assertions. | The lint rules in `vite.config.ts`, run by `vp check --deny-warnings`. |
| No tracked file, file name or commit message names another UI library. | `scripts/check-private-terms.mjs`, in `vp run verify` and the commit-msg hook, where `SOLIX_PRIVATE_TERMS` is set. CI sets it from a repository secret. |
| A component has one shape: one function per `Component.tsx` and its exported props type, `ElementProps<"element", typeof styles, OwnProps>` or `PolymorphicProps<T, typeof styles, OwnProps>` from `packages/core/src/parts.ts`, and one `createParts` call that keeps every member of `OwnProps`, and `children` when it renders them, off the root. `OwnProps` is an inline type literal, or an intersection of them, and only `Partial<Record<DisplayPropName, never>>` may stand on its own in it. A component typed `PolymorphicProps` declares a generic overload and then one for its default element, and renders a `dynamic()` root; one typed `ElementProps` returns the element it names. Its `root` is spread on that element and `part(name)` inline on each other part, an intrinsic element. No `class` or `style` is written by hand, and no file in `packages/core/src` but `parts.ts` calls `stylex.attrs` or `stylex.props`. The barrel is sorted and exports each component with its props type, and every `--solix-*` token is used. No array or argument list outside the table in `packages/core/src/style-prop-table.ts` names two style props. | `tests/library-conventions.test.ts`. |
| A component is rendered by the app, described by a feature file, and listed in the contract skill. | `apps/playground/tests/consumer.test.ts`, `tests/library-conventions.test.ts` and `packages/core/tests/component-contract.test.tsx`. |
| Skills, agents and this table stay true to the repository, every agent is started by an installed skill, and every verification skill was last confirmed against a commit that HEAD contains, which CI checks out the whole history to tell. The paths a verification skill tells you to diff are the paths its covered-code table covers. A skill names the catalog in `pnpm-workspace.yaml` instead of copying its versions. | `tests/repository-conventions.test.ts`. |
| Every row of this table is compact, with one space on each side of each cell border and no padding, so a rule edit changes one line. The formatter leaves this file alone. | `tests/repository-conventions.test.ts`, and `fmt.ignorePatterns` in `vite.config.ts`. |
| Every list of the playground's journeys names the same journeys, each feature file has the same four sections, and no two test servers share a port. | `tests/playground-verification-conventions.test.ts`. |
| The evidence comment on a pull request holds one row per journey, linked once to that journey's section of the full report by the anchor GitHub gives its heading, with each engine's count of passed observations, and fits in GitHub's 65,536 characters for 200 journeys on every engine. Steps, screenshots, recordings and observed values stay in the full report. | `tests/evidence-summary.test.ts`. |
| `vp run verify` runs before each commit and in CI, on every browser engine, and CI gives it the private-term list. | `tests/repository-conventions.test.ts`. |
| Components follow Solid 2.0, not React or Solid 1.x. | `solid2-kit check` and `solid2-kit doctor`. |
| A dependency version is written once, in the catalog. | `catalogMode: strict` in `pnpm-workspace.yaml` and `tests/workspace-rules.test.ts`. |
| The root `package.json` sets `engines.node` to a range with a lowest major, and `@types/node` shares that major. In every `.yml` or `.yaml` workflow, each `node-version-file:` is `package.json`, no line says `node-version:`, and `node-version-file: package.json` lines are at least as many as `runs-on:` lines. No `.node-version`, `.nvmrc` or `.tool-versions` file exists outside generated and installed files, no manifest sets `devEngines.runtime`, and no manifest but the root sets `engines.node`. | `tests/workspace-rules.test.ts`. |
| The project is MIT-licensed, and every library package declares the same licence as the root. | `tests/workspace-rules.test.ts`. |
| A library's peer range accepts the version the catalog pins. | `tests/workspace-rules.test.ts`. |
| Compiler settings are written once, in `tsconfig.base.json`. | `tests/workspace-rules.test.ts`. |
| A library has no runtime dependency. A library names another library of this repository as a `workspace:^` peer, linked as a `workspace:*` devDependency. | `tests/workspace-rules.test.ts`. |
| A public module of the primitives package is a kebab-case `src/<name>.ts` that exports one function named for the file, such as `createToggle` in `create-toggle.ts` or `getHotkeyHandler` in `get-hotkey-handler.ts`, and its types. A helper that no consumer imports is `internal-<topic>.ts`, and the shared types are in `types.ts`, which exports only types. | `tests/primitive-conventions.test.ts`. |
| The primitives package's barrel re-exports each public module with its types, then `types.ts`, in file-name order, and no internal module. | `tests/primitive-conventions.test.ts`. |

| A primitive keeps no state at module level: no `let` or `var`, no static class field, no module-level initialiser that holds `new`, a regular expression literal or a call other than `Symbol(...)` and `Object.freeze(...)`, and no array or object literal that is not `as const`. | `tests/primitive-conventions.test.ts`. |
| A primitive reads once, untracked, when it is created, only an argument named `initial*`, `default*` or `final*`, and an argument is typed `ReadOnce` exactly when it is so named. | `tests/primitive-conventions.test.ts`. |
| In a primitive's body, outside nested closures, no parameter is destructured, and no declaration, `Object.assign` source or spread takes its value from a parameter except through a call, with each binding resolved by the type checker. | `tests/primitive-conventions.test.ts`. |
| A primitive writes no style and no class: it assigns no `style`, `className` or `classList`, calls none of their writers, passes `class` or `style` to no attribute writer, even through a constant, and creates no `<style>` element or adopted style sheet. | Each rule in `tests/support/primitive-rules/` passes the fixture in `tests/fixtures/primitive-rules/allowed`, which holds only what it allows, and flags every line of the fixture in `tests/fixtures/primitive-rules/forbidden` that breaks it, and nothing else. | The fixture tests in `tests/primitive-conventions.test.ts`. |
