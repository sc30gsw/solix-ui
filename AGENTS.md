# AGENTS.md

Every rule in this repository is enforced by a check. Run all of them with `vp run verify`. The same command runs before each commit and in CI.

| Rule | Enforced by |
| --- | --- |
| Use Vite+ for development, builds, tests, linting and formatting. | The pnpm override that resolves `vite` to Vite+, the `vite-plus/prefer-vite-plus-imports` lint rule, and `tests/workspace-rules.test.ts`. |
| Code is formatted, lint-clean and type-correct. | `vp check --deny-warnings`. |
| Code has one style for functions, imports, exports, comparisons and type assertions. | The lint rules in `vite.config.ts`, run by `vp check --deny-warnings`. |
| No tracked file, file name or commit message names another UI library. | `scripts/check-private-terms.mjs`, in `vp run verify` and the commit-msg hook, where `SOLIX_PRIVATE_TERMS` is set. CI sets it from a repository secret. |
| A component has one shape: one function per `Component.tsx` and its exported props type, `ElementProps<"element", typeof styles, OwnProps>` or `PolymorphicProps<T, typeof styles, OwnProps>` from `packages/core/src/parts.ts`, and one `createParts` call that keeps every member of `OwnProps`, and `children` when it renders them, off the root. `OwnProps` is an inline type literal, or an intersection of them, and only `Partial<Record<DisplayPropName, never>>` may stand on its own in it. A component typed `PolymorphicProps` declares a generic overload and then one for its default element, and renders a `dynamic()` root; one typed `ElementProps` returns the element it names. Its `root` is spread on that element and `part(name)` inline on each other part, an intrinsic element. No `class` or `style` is written by hand, and no file in `packages/core/src` but `parts.ts` calls `stylex.attrs` or `stylex.props`. The barrel is sorted and exports each component with its props type, and every `--solix-*` token is used. No array or argument list outside the table in `packages/core/src/style-prop-table.ts` names two style props. | `tests/library-conventions.test.ts`. |
| A component is rendered by the app, described by a feature file, and listed in the contract skill. | `apps/playground/tests/consumer.test.ts`, `tests/library-conventions.test.ts` and `packages/core/tests/component-contract.test.tsx`. |

| Every row of this table is compact, with one space on each side of each cell border and no padding, so a rule edit changes one line. The formatter leaves this file alone. | `tests/repository-conventions.test.ts`, and `fmt.ignorePatterns` in `vite.config.ts`. |

| `vp run verify` runs before each commit and in CI, on every browser engine, and CI gives it the private-term list. | `tests/repository-conventions.test.ts`. |
